# dsh-better-session

简体中文 | [English](README.en.md)

为 DeepSeek Harness 补充会话管理能力：批量操作会话、彻底删除、统一管理已归档会话，以及重做某一轮对话。

> ⚠️ **删除不可恢复。** 会话会被直接从磁盘移除，不进回收站，空间才真正释放。

## 安装

```sh
dsh plugin --profile web add git@github.com:Terie412/dsh-better-session.git
```

`web` 换成你用的 profile 名。装完在 **设置 → 插件** 确认已开启。

## 功能

### 1. 批量操作会话

右键任意会话 → **批量操作**，进入多选：

- 每条会话左侧出现复选框，点一下勾选
- 侧栏底部出现 **全选 / 批量归档 / 批量删除 / 退出**
- **Esc** 退出多选

> 会话正在运行时，复选框位置被状态圆点占用。这时用右键菜单的「批量操作」选中它。

### 2. 删除会话

右键任意会话 → **删除会话**，弹窗确认后永久删除。

- **运行中的会话也能删**：会先停掉它正在执行的工作，再移除文件
- 删除范围包括会话记录和本地缓存，空间真正回收

### 3. 管理已归档会话

**设置 → 会话设置**，列出所有已归档会话，显示标题、占用空间、最后修改时间。

- 单条：**恢复**（放回侧栏）或 **删除**
- 批量：勾选后 **批量恢复** 或 **批量删除**
- 顶部 **全选** 可一次选中全部

### 4. 重做某一轮

已经发出去的一轮做错了，不必新开会话，直接重做。

**操作**：鼠标移到自己的消息上，出现 **重做这一轮**，点开可改原文再发送。

**效果**：旧的这一轮在模型历史中被替换成摘要，然后按你改后的内容重新提问。

- 轮次文本不足 600 字时不做摘要，直接用一段说明包住原文，更快更省
- 只改写模型看到的历史，界面上原来那一轮仍然保留
- **已经写入的文件不会被撤销**，这一点与编辑文件不同
- 仅对**已结束**的轮次可用，运行中不显示按钮

## 说明

- 归档不占额外空间、可恢复，想留后路就归档；确实不要了再删除
- 删除前一定会弹窗确认
