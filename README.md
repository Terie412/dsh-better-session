# dsh-better-session

简体中文 | [English](README.en.md)

为 DeepSeek Harness 补充会话管理能力：批量操作会话、彻底删除、统一管理已归档会话。

> ⚠️ **删除不可恢复。** 会话会被直接从磁盘移除，不进回收站，空间才真正释放。

## 安装

```sh
dsh plugin --profile web add git@github.com:Terie412/dsh-better-session.git
```

`web` 换成你用的 profile 名。装完在 **设置 → 插件** 确认已开启。

## 功能

### 1. 批量操作会话

右键任意会话 → **批量操作**，进入多选：

- 每条会话左侧出现复选框，点一下勾选
- 侧栏底部出现 **全选 / 批量归档 / 批量删除 / 退出**
- **Esc** 退出多选

> 会话正在运行时，复选框位置被状态圆点占用。这时用右键菜单的「批量操作」选中它。

### 2. 删除会话

右键任意会话 → **删除会话**，弹窗确认后尝试永久删除；如果会话仍驻留内存，会提示重启后重试。

- **仍驻留内存的会话不会直接删文件**：先归档并停止工作，再提示重启 DeepSeek Harness；重启后从 **设置 → 会话设置** 重试删除（不要先打开或恢复它）
- 删除失败会明确提示，不会把仍在内存中的会话伪报为删除成功；成功删除会移除会话记录和本地缓存

### 3. 管理已归档会话

**设置 → 会话设置**，列出所有已归档会话，显示标题、占用空间、最后修改时间。

- 单条：**恢复**（放回侧栏）或 **删除**
- 批量：勾选后 **批量恢复** 或 **批量删除**
- 顶部 **全选** 可一次选中全部

### 4. 快捷切换会话

- **Alt + ←**：上一个会话；**Alt + →**：下一个会话
- 按左侧列表当前排列顺序（包括置顶、手动排序、工作区分组），不是最近访问顺序
- 跳过归档、折叠组及「显示更多」尚未展开的会话；已渲染但在滚动区外的会话仍可切换
- 头尾停止、不循环；当前会话不在列表中时不切换；输入框内也有效，弹窗打开时不切换
- 快捷键可在快捷键参考中查看；Windows/macOS 桌面端可自定义，Web/Linux 固定使用这组按键并拦截浏览器前进／后退

### 5. 后台完成通知

在 **设置 → 会话设置 → 完成通知** 中开启，首次开启时允许系统通知；默认关闭，偏好保存在当前设备的浏览器存储中。

- 普通会话正常完成一轮时提醒；有未完成的长期目标时不提醒中间轮，目标完成且最终回复成功结束后才提醒
- 正在查看且窗口有焦点的会话不提醒；切到其他会话、窗口失焦或最小化时提醒
- 取消、失败、子智能体、归档会话不提醒；只接收实时事件，刷新或重连不补发历史通知
- 点击通知尝试聚焦窗口并打开对应会话；**测试通知**可单独验证权限，不会自动开启完成提醒
- 必须保持应用运行且通知服务连接正常；窗口聚焦效果、通知位置、声音及是否被免打扰拦截由桌面环境决定
- Web 需要安全上下文（HTTPS 或 localhost）；同源多窗口尽力去重、抑制另一窗口正在查看的会话通知；窗口忙碌/挂起或缺少 Web Locks、浏览器存储时不保证跨窗口仲裁，不同浏览器/设备各自提醒

## 说明

- 归档不占额外空间、可恢复，想留后路就归档；确实不要了再删除
- 删除前一定会弹窗确认
- 操作结果在页面顶部居中显示悬浮提示，不占侧栏或设置页空间；成功 4 秒、错误 8 秒后消失，也可手动关闭；批量相同错误合并显示
